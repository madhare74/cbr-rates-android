# Курсы ЦБ

Android-приложение с официальными курсами валют Центрального банка РФ.
Данные загружаются напрямую с `https://www.cbr.ru/scripts/XML_daily.asp`.

## Возможности (версия 1)
- Курсы на дату установления ЦБ, номинал (10, 100 … единиц), изменение к предыдущему дню (▲ / ▼ / —).
- Избранное сверху (по умолчанию USD, EUR, CNY, KZT) — звёздочка или долгое нажатие.
- Поиск по коду и названию, обновление жестом «потянуть вниз».
- Без сети — последние сохранённые курсы с пометкой «Нет соединения. Данные на ДД.ММ.ГГГГ».
- Конвертер валюта ⇄ рубли с учётом номинала, русский формат чисел.
- Android 8.0+, Kotlin, Jetpack Compose, Material 3, светлая и тёмная тема.

## Сборка
Собирается в GitHub Actions (`.github/workflows/android.yml`):
- `build` — unit-тесты и debug-APK (артефакт `kursy-cb-debug-apk`);
- `ui-tests` — UI-тесты на эмуляторе Android 11.

Локально: `./gradlew testDebugUnitTest assembleDebug`.

Автотесты используют сохранённые образцы ответов ЦБ (`app/src/sharedTest/fixtures`)
и не зависят от доступности сайта.
